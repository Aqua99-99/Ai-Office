# AI 사무실

AI 직원 팀(팀장·개발자·테스터·보안·디자이너·배포)이 내 프로젝트를 알아서 점검하고 고친 뒤 보고해요.
GitHub에서 돌아가서 **컴퓨터가 꺼져 있어도** 정한 요일 아침마다 일해요.

## 내 정보는 나만 봐요
- 이 저장소는 모두가 복사해 가는 **원본**이에요. 여기에는 프로그램만 있고 개인 정보는 없어요.
- 쓰는 사람은 각자 **내 GitHub 안에 비공개 사무실**을 하나 복사해서 만들어요.
  내 프로젝트·보고서·결과물·AI 키는 그 비공개 저장소에만 들어가요. 원본 주인도 볼 수 없어요.
- GitHub 무료 시간과 AI 키도 각자 자기 것을 써요.
- 안전을 위해 직원들은 **비공개 저장소에서만** 일해요. (원본·공개 저장소에서는 쉬어요)

## 시작하기 (5분, 한 번만)
1. 오른쪽 위 **Use this template → Create a new repository** → 이름 적기 → **Private** 고르기 → **Create repository**
2. **AI 사무실 사이트**에 들어가서 "처음이에요" 안내대로 열쇠(토큰)를 만들고 로그인해요.
   사이트 주소는 이 저장소 오른쪽 **About**에 있어요.
3. 사이트에서 프로젝트 ZIP을 올리고 **업무 지시서**를 쓰면 끝이에요.

## 사이트에서 할 수 있는 일
- 픽셀 사무실에서 직원들이 일하는 모습 보기
- 프로젝트 ZIP 올리기 (90MB까지) → 팀장이 알아서 파악해요
- 업무 지시서: 기간·요일·할 일·하루 최대 시간
- 지금 바로 일 시키기
- 보고서 보기, 결과물 ZIP 받기 (프로젝트마다 최근 5개)
- **AI 열쇠함**: 내 AI 키를 넣으면 어느 회사 키인지 알아서 찾아요. 키는 잠가서 내 저장소 비밀 금고에 넣어요.

## AI 두뇌
- 넣은 키 순서대로 쓰고, 한도가 차면 다음 AI로 넘어가요. 지원: Gemini, OpenRouter, Groq, OpenAI, Claude API, OpenAI 호환 주소
- 키가 없거나 다 한도에 걸리면 GitHub 서버 안의 **작은 AI**(무료 오픈소스)가 이어서 해요. 느리지만 코드가 밖으로 나가지 않아요.
- 무료 등급 AI는 보낸 코드가 학습에 쓰일 수 있어요. 중요한 프로젝트는 업무 지시서에서 **작은 AI만**을 고르세요.

## 알아둘 점
- 비공개 저장소의 GitHub 무료 시간은 한 달 2,000분이에요. 하루 120분 × 주 5일이면 딱 맞아요.
- 내 컴퓨터에서 돌리는 방식도 있어요: `ai-office` 폴더를 내려받아 `AI-Office.vbs`를 더블클릭 (Node.js, Ollama 필요).
- AI가 고친 결과라 실수가 있을 수 있어요. 쓰기 전에 꼭 한 번 확인하세요.
