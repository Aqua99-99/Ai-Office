AI 사무실

내 비공개 GitHub 저장소에서 AI 직원들이 일해요. 컴퓨터가 꺼져 있어도 돼요. 내 정보는 나만 봐요.

자세히 (보통은 그대로 두세요)
처음이에요 — 내 사무실 만들기 (5분, 한 번만)

사무실은 사람마다 내 GitHub 안의 비공개 저장소로 따로 만들어요. 내 코드·보고서·AI 키는 나만 볼 수 있고, 이 사이트 주인도 볼 수 없어요.

  1. 내 비공개 사무실 만들기
    여기를 눌러 원본을 복사해요 → 저장소 이름 적기 (예: my-ai-office) → Private 꼭 고르기 → Create repository
  2. 열쇠(토큰) 만들기
    여기를 눌러 새 열쇠 만들기
    • 이름: AI 사무실, 기간: 원하는 만큼 (예: 90일)
    • Repository access → Only select repositories → 방금 만든 사무실 하나만 고르기
    • Permissions → Repository permissions에서 4개를 Read and write로: Actions, Contents, Issues, Secrets
    • Generate token → 나온 열쇠(github_pat_…)를 복사
  3. 위 칸에 넣고 들어가기
    저장소: 내아이디/my-ai-office, 열쇠: 방금 복사한 것

열쇠는 이 브라우저에만 저장되고 GitHub 말고는 어디에도 보내지 않아요. 사무실 저장소 하나만 열 수 있어서 안전해요.
